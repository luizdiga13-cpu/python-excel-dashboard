# 📊 Automação Dashboard Excel

Sistema profissional de automação de relatórios Excel desenvolvido em Python.

---

# 🚀 Funcionalidades

✅ Upload de arquivos Excel  
✅ Dashboard interativo  
✅ Geração automática de relatórios  
✅ Integração com banco de dados SQLite  
✅ Gráficos automáticos  
✅ Exportação Excel  

---

# 🛠 Tecnologias Utilizadas

- Python
- Streamlit
- Pandas
- Plotly
- OpenPyXL
- SQLite
- SQLAlchemy
